# Punarnava

Plastic that becomes new again — investor site and founder operating system for a plastic recycling venture in Bangalore.

Built with Next.js, TypeScript, Tailwind CSS and shadcn/ui. See `CLAUDE.md` for the full blueprint.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Copy `.env.example` to `.env.local` for private-area passwords (from Phase 3).

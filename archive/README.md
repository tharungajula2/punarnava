# Archived presentation material

The former OS, case study, public sources page and contact components live here. They are outside `src/app`, so Next.js does not expose their routes. The research, assumptions, simulation engine and shared visual components remain in `src` where the investor presentation still uses them.

To restore a page, move its route back under `src/app` and restore any supporting components from `archive/components`. Review its content and links before publishing: these screens were written for the earlier seven-section OS and contain illustrative simulation data.
